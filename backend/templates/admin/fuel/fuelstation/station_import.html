How it works

Matched by OPIS Truckstop ID only.

  1. Upload. The file is checked: real CSV/XLSX content, no macros or formulas, size and row limits.
  2. Preview. Each row is classified as new, update, unchanged or invalid, with current → new values. The database is not touched.
  3. Confirm. The previewed changes are applied together in one transaction. Invalid rows are skipped and listed in a downloadable error report.
